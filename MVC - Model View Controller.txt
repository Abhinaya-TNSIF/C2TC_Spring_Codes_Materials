DATA BINDING

Types of data binding in angular

* Interpolation TS to HTML (one way)
* Property Binding TS to HTML (one way) (but shares only the property not data ie. Photo,Styles , Phara)
* Event Binding Carrying the events Template -> Component (one way)
* Two way binding Component -> Template



* Interpolation:

Syntax {{ expression }}

Example: 
<h1>{{title}}</h1>


* Property Binding

Syntax [property]="exp"

Example:
<img[src]="imageUrl" alt="Angular Logo">

Use case;
Dynamically binds DOM property Src,URl...
